Network Assurance Knowledge Base

ENCOR 350-401 v1.2 Domain 4 (Network Assurance — 10%) reference for Syslog, Flexible NetFlow, SPAN, IP SLA, and SNMPv3.

Syslog & Logging

Syslog Severity Levels (0–7) & UDP 514

Cisco IOS-XE classifies log messages from 0 (Emergencies) down to 7 (Debugging). Configuring logging trap <level> forwards all messages with a severity number less than or equal to (≤) the configured level to the Syslog server on UDP 514 (default is informational / level 6).

Syslog Message Format

Standard IOS format: %FACILITY-SEVERITY-MNEMONIC: description (e.g., %LINEPROTO-5-UPDOWN). Include service timestamps log datetime msec for accurate forensic correlation across devices.

Packet Capture & Traffic Telemetry

SPAN, RSPAN & ERSPAN (Port Mirroring)

SPAN (Switched Port Analyzer): Mirrors local source ports/VLANs to a local destination port on the same switch. RSPAN (Remote SPAN): Carries mirrored traffic across Layer 2 trunks using a dedicated remote-span VLAN. ERSPAN (Encapsulated Remote SPAN): Encapsulates mirrored frames in GRE (IP Protocol 47) to reach a remote analyzer across a Layer 3 routed network.

Flexible NetFlow (FNF) Architecture

Exports IP flow telemetry (UDP 2055 or 9995) using three modular building blocks: 1. Flow Record (defines key match fields like Src/Dst IP, Ports, Protocol, ToS, and non-key collect counters), 2. Flow Exporter (destination collector IP, UDP port, source interface), and 3. Flow Monitor (binds Record + Exporter and is applied to an interface).

Active Probing & SNMPv3

IP SLA (Internet Protocol Service Level Agreement)

Generates synthetic active probe traffic (ICMP Echo, UDP Jitter, HTTP, DNS) to measure latency, jitter, packet loss, and MOS voice quality. Often paired with Object Tracking (track 1 ip sla 1 reachability) for automated static route or HSRP failover.

SNMPv3 Security Levels (Simple Network Management Protocol)

Uses UDP 161 (polling) and UDP 162 (traps) with User-based Security Model (USM): noAuthNoPriv (username only, no auth/encryption), authNoPriv (SHA/HMAC authentication, no encryption), and authPriv (SHA authentication + AES encryption — Cisco recommended).

Change logging trap to see which severity levels (≤ configured threshold) are sent to the Syslog server.
